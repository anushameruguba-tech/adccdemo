# ADCC Demo Website

A demo website concept for American Dry Cleaning Company. It is plain HTML, CSS and JavaScript with no build step.

Pages: Home, Services & prices, Our story, Sustainability, Branches, FAQs, Contact, Book a collection.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Publish
Turn on GitHub Pages under Settings › Pages, choose "Deploy from branch", then `main` / root.
